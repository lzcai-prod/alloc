# alloc

SGD allocation review for one investor's whole book. Two sleeves (U18 growth, core = U12 + U15 + UOB), a vol-matched ALLW scoreboard, and a whole-book SPY put-spread hedge (proposed, nothing placed).

- `docs/` plan, status, decision record
- `data/` distilled results (no account numbers, no raw statements) and the hashed decision record
- `db/` Neon schema and load statements (project `alloc`)
- `analysis/` the Python used for the review (needs private inputs that are not in the repo; see `analysis/README.md`)

Cost and risk figures are analysis, not advice. Nothing here places orders.
